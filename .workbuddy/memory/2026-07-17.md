# 2026-07-17

## 图标引用整理（来自 appstore-images.zip）
- zip 内含 windows / android / ios 三套图标（112 个文件）。原 `manifest.webmanifest` 引用 `icon-192.png`、`icon-512.png`，`index.html` 引用 `icon-512.png` 作 apple-touch-icon，但这两个 PNG 此前都不在仓库里（只有 `icon.svg`），引用是断的。
- 最省事的引用方案：从 zip 抽出与 manifest 已声明文件名一致的那几个 PNG 放到根目录，manifest 无需改：
  - `icon-192.png` ← `android/launchericon-192x192.png`
  - `icon-512.png` ← `android/launchericon-512x512.png`
  - `apple-touch-icon.png` ← `ios/180.png`（iOS Safari 不支持 SVG 的 apple-touch-icon，需 PNG；180px 是 iPhone 推荐上限，体积小）
- `manifest.webmanifest` 维持 `icon.svg`(any) + `icon-192.png` + `icon-512.png` 三档即可覆盖 PWA 安装；SVG 作 `any` 目的、可无限缩放。zip 本身保留作源文件归档。

## 修复 file:// 链接无法导航
- 根因：`fullUrl()` 在 file 模式只返回 `location.pathname + '#' + currentPath` → `/C:/.../index.html#/1`，缺 `file://` 协议头，复制到别处点击时浏览器不按 file URL 解析。
- 修法：`fullUrl()` file 分支改为 `'file://' + location.pathname + '#' + currentPath` → `file:///C:/.../index.html#/1`，复制出的链接可直接跳转。

## 语言中立：去掉「本地」文字
- `hostDisplay` 在 file 模式原显示 `📄 本地/`，按用户要求去掉中文「本地」，改为纯 emoji `📄 /`。全项目现已无任何中文文字，提示一律用 emoji（✅/🔄/💾 等）。

## 图标更新（透明底 + 双部署深链回退）
- 用户更新 `appstore-images.zip`：新版 `android/launchericon-192x192.png` / `512x512` 现为透明底（RGBA，四角透明）。重新抽取覆盖 `icon-192.png` / `icon-512.png`，manifest 无需改（purpose=any，Android PWA 支持透明）。
- `apple-touch-icon.png` 仍来自 `ios/180.png`，白底不透明（iOS 主屏图标不能透明，保持即可）。
- `index.html` 体积 16KB 级，CSS 内联即可，无需拆分（单文件请求少、SW 缓存一个文件、离线可用）。

## 双部署深链回退（COS + GitHub Pages）
- COS：用户已配 404 → index.html，深链直接可用。
- GitHub Pages 原生不支持 SPA 回退。新增根目录 `404.html`：stash `location.pathname+search` 到 sessionStorage 后 `location.replace('/')`；`index.html` 启动早期读 sessionStorage 并 `history.replaceState` 还原深链路径。
- 已安装的 Service Worker（navigate 请求一律返回缓存的 index.html）本身已覆盖热路径；`404.html` 仅作首次冷启动兜底。

## 路由改为全 hash 统一 + 焦点同步
- 用户确认 GitHub 是**根域自定义域名**（非 `/note/` 子路径），故不再需要 hybrid（真实 pathname）方案。
- 改动 `index.html`：
  - `keyPath()` / `navigateTo()` / 监听器统一走 `location.hash`，删除 `isFile` 路由分支、`pushState`/`popstate` 的 hybrid 逻辑，以及启动时的 sessionStorage 还原块（此前双部署回退方案已废弃）。
  - `hostDisplay` 把 `#/` 并进灰色前缀：线上 `host/#/`、file 模式 `📄 /#/`。
  - `fullUrl()` 统一为 `location.origin + location.pathname + '#' + currentPath`（本地文件三斜杠 `file:///...`、线上 `https://host/#/...`）。
  - 新增 `saveNow()`（立即落盘，清掉防抖定时器）；`blur`/`visibilitychange:hidden` → saveNow，`focus`/`visibilitychange:visible` → load，保证同路径多标签页/窗口内容一致。
- `404.html` 改为把遗留真实路径请求重定向到根域 hash 路由：`location.replace('/#' + location.pathname + location.search)`（依赖 GitHub/COS 皆根域；逻辑仅冷启动兜底，SW 装好后由 SW 直接返回 index.html）。
- 收益：本地与线上行为完全一致、代码更短、两部署笔记 key 完全相同（无子路径重复前缀问题）。
