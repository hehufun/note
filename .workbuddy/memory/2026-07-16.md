# 2026-07-16

## 网页记事本 index.html 修复
- 问题1 中文路径乱码：路径里的 `%E7%9A%84` 这类 URL 编码中文在地址栏/输入框显示为乱码（尤其 file:// 模式 hash 不解码）。
  - 新增 `decodePath()`（按 `/` 分段 `decodeURIComponent`，带 try/catch 兜底）与 `encodePath()`（`encodeURIComponent` 分段）。
  - `keyPath()` 与 `navigateTo()` 改为先 `decodePath` 再 `normalize`，输入框显示解码后的中文。
- 问题2 点击复制整条链接：顶部 `.addr`（灰色 host + 地址区）加 `id="addr"` 与 `title`，点击（非输入框区域）即复制完整链接。
  - `fullUrl()` = `location.origin + encodePath(currentPath)`（file 模式为 `pathname + '#' + enc`）。
  - 用 `navigator.clipboard` 复制，失败回退 `document.execCommand('copy')`；复制后底部 toast 提示“已复制链接 🔗”。
  - 注意：localStorage key 始终用解码后路径，保证“再次进入”命中同一条笔记。
- 修订：用户要求复制的链接也用解码后的中文（如 `http://note.dupal.cn/速度` 而非 `%E9%80%9F...`）。
  - `fullUrl()` 改为直接 `location.origin + currentPath`（file 模式 `pathname + '#' + currentPath`），不再编码。
  - 现代浏览器粘贴带中文的链接会自动编码访问，可读性更好；同时删除了不再使用的 `encodePath()`。
- 校验：node 对两段 inline script 做语法检查均 OK。
