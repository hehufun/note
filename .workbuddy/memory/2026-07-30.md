## KV key 碰撞问题修复 & 部署准备
- 发现 `syncId + currentPath` 直接拼接的 KV key 设计存在碰撞风险（如 syncId="a/b"+path="/c" 与 syncId="a"+path="/b/c" 算出相同 key）
- 改用 **方案B**：URL 格式改为 `PUT/GET /{sid}?p={path}`，syncId 放 URL path，pagePath 放 query param
- Worker 端 `decodeURIComponent` 各自解码后以 `"::"` 分隔存为 KV key，彻底防碰撞
- 创建 `note-sync-worker/` 项目目录，包含 `src/index.js` + `wrangler.toml`
- `index.html` 中 sync 函数从 `setTimeout` 模拟替换为真实 gzip + fetch 实现（CompressionStream）
- 更新 `cloud-sync-deploy.md` 文档匹配新 API 设计
- wrangler 尚未安装，部署前需 `npm install -g wrangler` 或 `npx wrangler`
