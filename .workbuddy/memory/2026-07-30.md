# 2026-07-30

## 锁定/解锁编辑区功能
- 在 top-bar 的 statusIcon (💾) 左侧添加了 lockIcon (🔐/🔒)
- 点击切换 textarea 的 readOnly 属性
  - 🔐 默认态：可编辑
  - 🔒 锁定态：只读（可滚动/选择/复制，不可编辑）
- 锁定态添加 `.locked` CSS class（降低透明度视觉反馈）
- keydown 和 input 事件添加 `isLocked` 守卫防止意外写入
- 锁图标从 🔐 改为 🔓（开锁）/🔒（锁定），更直观
- 编辑区鼠标悬浮光标改为 ✍️ emoji（SVG data URL 自定义 cursor）
- 替换为 JS 驱动的自定义光标（隐藏原生 cursor，div 模拟跟随鼠标）
- 滚动方向动态光标：向下滚 👇、向上滚 👆、停止 500ms 恢复 ✍️，带 scale 弹性动效
- 锁定态不显示自定义光标
